# Sahel Microfinance Bank — Branch Operations Runbook

> Internal. Version 2.4. Owner: Head, Branch Operations.

## Opening procedure

1. Dual custody of the vault is mandatory. Neither key holder may open alone.
2. Cash count is reconciled against the previous day's closing position before the
   branch opens to customers.
3. Any variance above NGN 5,000 is reported to Internal Control the same morning.

## Cash holding limits

| Branch tier | Maximum overnight holding (NGN) | Escalation |
| --- | --- | --- |
| Tier 1 | 25,000,000 | Regional Manager |
| Tier 2 | 12,000,000 | Regional Manager |
| Tier 3 | 5,000,000 | Head, Branch Operations |

Holdings above the limit require an evacuation to the correspondent bank the same day.

## Downtime procedure

If the core banking application is unavailable for more than thirty minutes:

- Switch to manual ticketing using pre-numbered vouchers
- Cap individual withdrawals at NGN 100,000 pending restoration
- Log every manual transaction for same-day capture on restoration
- Notify the IT service desk and the Regional Manager

Manual ticketing may not continue beyond one business day without written approval
from the Head of Branch Operations.
